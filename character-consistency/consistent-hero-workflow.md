# Consistent hero workflow

## Workflow

1. Create a master character sheet with facial descriptors and wardrobe anchors.
2. Use one approved reference image as the primary visual baseline.
3. Maintain a stable prompt formula: subject + descriptor + style + lighting + camera + environment.
4. Keep the same output aspect ratio and generation tool for comparison.
5. Test small variations separately (lighting, camera, background) rather than changing multiple identity traits at once.

## Example prompt

A cinematic portrait of Mara Voss, dark brown shoulder-length hair, hazel eyes, warm olive skin, subtle scar near right brow, black tailored jacket, silver ring, natural face shape, high-end editorial portrait, soft side lighting, shallow depth of field, 85mm lens, realistic textures, premium cinematic look.

## Best practice

When drift happens, revert to the master identity sheet and reintroduce only the scene change. This reduces unintended changes to key features.
