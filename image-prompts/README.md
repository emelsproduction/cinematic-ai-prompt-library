# Image prompts

This folder is dedicated to AI-generated still-image prompts and visual references.

## Organization

Use category folders and descriptive filenames so prompts are easy to search by style, subject, or tool.

## Suggested categories

- `cinematic/` — dramatic, high-end film looks
- `portrait/` — people, faces, close-ups, beauty, realism
- `product/` — luxury products, commercial shots, surfaces
- `environment/` — architecture, landscapes, interiors
- `fantasy/` — magical or stylized scenes
