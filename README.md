## Contribution standards

Each prompt should include:

- clear subject and mood
- visual style references
- output format (still image or video)
- model/tool used if known
- camera language and lighting notes
- a brief result note or best-use case

## Recommended local folder structure

- `image-prompts/` for still images
- `video-prompts/` for motion and clips
- `character-consistency/` for identity references and consistency workflows
- `camera-techniques/` for lens, framing, and movement techniques
- `documentation/` for templates, guides, and taxonomy
