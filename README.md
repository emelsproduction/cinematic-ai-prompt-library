# Cinematic AI Prompt Library

An open-source collection of cinematic AI image and video prompts, workflows, and production techniques.

## Browse the library

- [Image prompts](image-prompts/README.md) — prompts and workflows for generating still images.
- [Video prompts](video-prompts/README.md) — prompts and workflows for generating motion and video.
- [Character consistency](character-consistency/README.md) — references and techniques for keeping characters consistent across generations.
- [Camera techniques](camera-techniques/README.md) — camera language, framing, movement, and lens techniques for AI-generated media.
- [Documentation](documentation/README.md) — guides, conventions, and project documentation.

## Contributing

Add content to the folder that best fits its purpose. Include the model or tool used, relevant settings, and notes about the result when available. See [the documentation](documentation/README.md) for suggested contribution details.
