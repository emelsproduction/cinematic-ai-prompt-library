# Publishing and validation notes

The new templates in this library are original prompt drafts organized for practical adaptation. They have not been independently run through image or video-generation tools in this repository, so do not label them “tested” or imply guaranteed results. Model behavior, available controls, and output quality vary by tool and version.

## How to validate a template

1. Choose a tool/model and record its name, version, date, and relevant settings.
2. Run the prompt at least once with a documented seed where supported.
3. For video, note duration, aspect ratio, and any camera or motion controls.
4. Review the output against the file's review checklist; record failures as well as successes.
5. Revise one prompt element at a time and compare results.
6. Add a short **Tested with** section only after a real generation, including tool/version, date, settings, and observed limitations.
