## Recommended naming convention

Use folder and file names in lowercase with hyphens, for example:

- `cinematic-portrait.md`
- `slow-burn-opening.md`
- `luxury-watch-shot.md`

## Search strategy

Search by combination of:

- subject: portrait, product, city, character
- style: cinematic, realistic, noir
- camera: 35mm, 85mm, dolly-in, handheld
- tool: SDXL, Runway, Kling, Midjourney
